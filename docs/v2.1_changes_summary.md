### 2. Knights - Multiple Restrictions (NEW)

#### ❌ v2.0 LOGIC (INCOMPLETE):
- Knight must be active to perform actions
- Performing action makes knight inactive
- (No specific restriction on activate→action in same turn)
- (No piece limits documented)
- (No auto-deactivation after barbarian attack)

#### ✅ v2.1 CORRECT LOGIC (IMPLEMENT):

**Knight Piece Limits** (NEW):
- Each player has exactly **6 knights total**:
  - 2 Basic knights (strength 1)
  - 2 Strong knights (strength 2)
  - 2 Mighty knights (strength 3)
- Knights are upgraded in place (Basic → Strong → Mighty)
- Cannot recruit more knights once all 6 are on the board

**Timing Restrictions**:

**ALLOWED in same turn**:
- ✅ Recruit → Activate
- ✅ Action (becomes Inactive) → Activate again

**NOT ALLOWED in same turn**:
- ❌ Activate → Action (CANNOT activate THEN act with same knight)

**Movement Rules** (IMPORTANT):
- Active knight can move to **any** empty intersection connected by continuous path of **own roads**
- **NOT limited to 1 edge** - can move multiple edges in single move
- Can pass through intersections with own pieces (settlements, cities, knights)
- Cannot end on occupied intersection (even own knight)
- Auto-deactivates after move

**Displacement Rules** (IMPORTANT):
- Can only displace **weaker** knight (Basic < Strong < Mighty)
- Displacing knight must reach enemy knight via **own road network**
- Displaced knight owner must **immediately** relocate it:
  - To any empty intersection connected by **their own roads** from displacement point
  - Displaced knight keeps its active/inactive status
  - Can return to original spot if connected by their roads and now empty
  - If no valid destination exists along owner's road network, knight is **permanently removed** from board
- Displacing knight becomes **Inactive** after displacement

**Auto-Deactivation Rules** (IMPORTANT):
- Knights are ONLY deactivated automatically, NEVER manually
- **After Barbarian Attack**: ALL active knights become inactive (win or lose)
- **After Knight Actions**:
  - Moving knight along road network → inactive
  - Displacing weaker knight → inactive (moving knight only, displaced keeps status)
  - Chasing robber → inactive

**Action Follow-Ups**:
- **Displacement**: Displaced knight owner sees relocation UI with valid destinations
- **Chase Robber**: Player must move robber to new hex (triggers standard robber logic: choose hex, steal card)

**Detailed Rules**:
1. A knight must be **Active** to Move, Displace, or Chase Robber
2. Performing ANY action **immediately** makes knight Inactive
3. You CAN activate a knight on the same turn you recruit it
4. You CAN activate a knight on the same turn it performed an action (re-activating)
5. You CANNOT have a knight activate and then immediately use it for an action

**Example Scenarios**:

✅ **VALID**:
- Turn 1: Recruit knight (inactive) → Activate (pay 1 grain) → Knight is active but cannot act
- Turn 2: Move knight → Knight becomes inactive → Activate again (pay 1 grain) → Knight active again

❌ **INVALID**:
- Activate knight (pay 1 grain) → Move knight (NO! Cannot activate then act same turn)
- Recruit 7th knight (NO! Only 6 total allowed)
- Recruit 3rd basic knight (NO! Only 2 basic allowed)

**IMPACT**:
- Knights require **2-turn cycle** to be useful after recruitment
- Turn 1: Recruit + Activate
- Turn 2: Use action (move/displace/chase)
- This is MORE RESTRICTIVE than typical implementations
- Piece limits match physical board game constraints
- Auto-deactivation after barbarian attack adds strategic depth

#### ADD v2.1 Movement Pathfinding:
```typescript
// Find all reachable intersections via road network (BFS/DFS)
function getReachableIntersections(gameState, knightId, playerId) {
  const knight = gameState.knights.find(k => k.id === knightId);
  const playerRoads = gameState.roads.filter(r => r.playerId === playerId);

  // BFS from knight's current position along player's roads
  const visited = new Set();
  const queue = [knight.vertexId];
  const empty = [];
  const displacement = [];

  while (queue.length > 0) {
    const vertex = queue.shift();
    if (visited.has(vertex)) continue;
    visited.add(vertex);

    const occupant = getVertexOccupant(gameState, vertex);

    if (!occupant) {
      empty.push(vertex);  // Empty intersection
    } else if (occupant.type === 'knight' && occupant.playerId !== playerId) {
      // Enemy knight - check if weaker
      if (knight.strength > occupant.strength) {
        displacement.push(vertex);  // Can displace
      }
    }

    // Add neighbors connected by player's roads (can pass through own pieces)
    const neighbors = getNeighborsViaRoads(vertex, playerRoads);
    queue.push(...neighbors);
  }

  return { empty, displacement };
}

// Get valid relocation destinations for displaced knight
function getDisplacedKnightDestinations(gameState, knightId, fromVertex) {
  const knight = gameState.knights.find(k => k.id === knightId);
  const ownerRoads = gameState.roads.filter(r => r.playerId === knight.playerId);

  // BFS from displacement point along owner's roads
  const reachable = [];
  const visited = new Set();
  const queue = [fromVertex];

  while (queue.length > 0) {
    const vertex = queue.shift();
    if (visited.has(vertex)) continue;
    visited.add(vertex);

    if (vertex !== fromVertex && !getVertexOccupant(gameState, vertex)) {
      reachable.push(vertex);  // Empty and reachable
    }

    const neighbors = getNeighborsViaRoads(vertex, ownerRoads);
    queue.push(...neighbors);
  }

  return reachable;
}
```

#### ADD v2.1 Auto-Deactivation:
```typescript
// After barbarian attack resolution
function resolveBarbarian(gameState) {
  // ... battle logic ...

  // Deactivate ALL active knights (all players)
  gameState.knights.forEach(knight => {
    if (knight.active) {
      knight.active = false;
      addLog(`${knight.id} deactivated after barbarian attack`);
    }
  });
}

// After knight move with displacement handling
function moveKnight(gameState, knightId, targetVertex) {
  const movingKnight = gameState.knights.find(k => k.id === knightId);
  const targetKnight = gameState.knights.find(k => k.vertexId === targetVertex);

  if (targetKnight && targetKnight.playerId !== movingKnight.playerId) {
    // Displacement - find relocation destinations for target knight
    const destinations = getDisplacedKnightDestinations(gameState, targetKnight.id, targetVertex);

    if (destinations.length === 0) {
      // No valid destinations - permanently remove
      removeKnight(gameState, targetKnight.id);
      addLog(`${targetKnight.id} was permanently removed (no valid relocation)`);
    } else {
      // Trigger relocation UI for displaced knight owner
      gameState.pendingAction = {
        type: 'relocateKnight',
        knightId: targetKnight.id,
        validDestinations: destinations,
        playerId: targetKnight.playerId
      };
      addLog(`${targetKnight.id} must be relocated`);
    }
  }

  // Move knight and deactivate
  movingKnight.vertexId = targetVertex;
  movingKnight.active = false;
  addLog(`Knight moved to ${targetVertex} and deactivated`);
}

// After chase robber
function chaseRobber(gameState, knightId) {
  const knight = gameState.knights.find(k => k.id === knightId);
  knight.active = false;
  addLog(`Knight chased robber and deactivated`);

  // Trigger robber placement UI
  gameState.pendingAction = { type: 'placeRobber', playerId: knight.playerId };
}
```

**Implementation Notes**:
- Knight movement requires **pathfinding algorithm** (BFS/DFS) along road network
- Displacement requires **two pathfinding passes**: one for moving knight, one for displaced knight relocation
- Displaced knight uses **owner's road network** from displacement point (not moving player's roads)
- Track `knightsActivatedThisTurn` and clear at end of turn
- No manual deactivation UI
- Follow-up actions for displacement (relocation) and chase robber (placement)
